# Matsés (Mayoruna) (mcf) Language Profile

**Family:** Pano  
**Peoples:** Povo Matsés  
**Geography:** Terra Indígena Vale do Javari (Rios Jaquirana e Javari (fronteira Brasil-Peru))  
**Status:** Low-resource Amazonian language  

## Typological Profile
- **Word Order:** SOV
- **Alignment:** Ergative-absolutive case marking
- **Morphology:** Agglutinative with suffixing and clitic attachment
