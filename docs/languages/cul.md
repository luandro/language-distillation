# Kulina (Madija) (cul) Language Profile

**Family:** Arawa  
**Peoples:** Povo Kulina  
**Geography:** Terra Indígena Vale do Javari (Rios Juruá e Curuçá (fronteira Vale do Javari / Acre))  
**Status:** Low-resource Amazonian language  

## Typological Profile
- **Word Order:** SOV / VSO com clíticos
- **Alignment:** Ergative-absolutive case marking
- **Morphology:** Agglutinative with suffixing and clitic attachment

## Related Languages & Hypothesis Policy (Invariant 8)
Related Panoan languages (Marúbo, Matsés, Matis, Korubo) share core cognates and grammatical markers. Cross-language evidence may generate candidate hypotheses, but never constitutes target-language truth.
